01 WELCOME

Your SAP expertise,
a new way of working.

You already know how to build SAP solutions. This exercise does not teach ABAP or CPI. It teaches the new TSP engineering workflow.

  • VS Code becomes your engineering workspace.
  • Claude Code works with you as an AI engineering agent.
  • ABAP FS connects that workspace to SAP.
  • The TSP Framework controls the development lifecycle.

You stay responsible for technical decisions and approvals. Claude helps you analyse, investigate, implement, validate and document.
No previous experience with VS Code, Claude Code, Git or MCP is needed. This guide starts from zero.

02

How the new workflow works

Four tools work together. You direct them. Every part of the exercise follows the same working cycle.

The cycle, step by step

  1. You

    Give Claude an instruction. At the start: Start a new project. Whenever you are unsure: What should I do next?

  2. Claude Code

    Reads the Framework instructions and the project context.

  3. TSP Framework

    Determines the current state and the next required action. You never need to work this out from the files yourself.

  4. Claude Code

    Carries out that action: investigates, proposes, creates or changes artifacts and code. It reaches SAP IX1 only through ABAP FS, with your own SAP user and authorizations. Before it changes files or runs commands it asks you, and you allow or deny each request.

  5. You

    Review what Claude brings you: a question, a functional gap, a technical recommendation or an approval request. If you do not agree, challenge it and ask why.

  6. You

    Answer, decide or approve, using your SAP judgment and the wording the Framework shows you.

  7. TSP Framework

    Records the decision, evidence and traceability in your project repository, versioned in Git.

  8. TSP Framework

    Checks whether the authorized scope is complete. If not, the cycle continues from step 3.

SAP Integration Suite is your own SAP BTP trial. You use it directly in the browser, only if your solution needs it. Claude and ABAP FS do not reach it.

Git / GitHub stores the engineering repository and its history. It does not replace SAP transports.

You stay responsible for technical decisions and approvals. Claude helps you analyse, investigate, implement, validate and document.

VS Code

Your engineering workspace: project files, Claude and SAP in one window.

  1. Download VS Code from code.visualstudio.com/download ↗.
  2. Run the User Installer. It needs no administrator rights and adds the code command to your PATH.
  3. Open the downloaded file and drag Visual Studio Code into Applications.
  4. Open VS Code.

B

Git

Versions the engineering repository: specifications, technical design, traceability, evidence and Framework state. Git does not replace SAP transports.

  1. Install Git for Windows from git-scm.com/install/windows ↗. The default options are fine; they include Git Credential Manager for GitHub sign-in.
  2. Open Terminal and run xcode-select --install, or follow git-scm.com/install/mac ↗.
  3. Close and reopen VS Code so it finds Git.
C

Python 3.11 or later

The Framework's validation and tracking tools are Python scripts that Claude runs in your project.

  1. Install Python from python.org/downloads ↗ using the Python Install Manager. If it offers to add Python to your PATH, accept.
  2. Install the macOS package from python.org/downloads ↗.
  3. Choose the current 3.x release. Python 3.11 is the minimum we support for this exercise.

After the version check below, you install the three Python packages the Framework needs.

CHECK GIT AND PYTHON

In VS Code, open Terminal → New Terminal and run:

git --version
python --version
git --version
python3 --version

Expected result Two version lines, for example git version 2.x and Python 3.1x.x.

If it doesn't work
  • "not recognized" / "command not found": close every VS Code window and reopen it, then retry. Installers only update the PATH for newly opened programs.
  • Windows opens the Microsoft Store when you type python: finish the Python Install Manager setup from python.org, then reopen VS Code.
  • Python older than 3.11: install a current version.
  • Still stuck? This is a local installation problem: contact the facilitator.

INSTALL THE FRAMEWORK'S PYTHON PACKAGES

In the same terminal, run this once. These are exactly the packages listed in the Framework's requirements.txt.

python -m pip install "PyYAML>=6.0,<7" "openpyxl>=3.1,<4" "python-docx>=1.2,<2"
python3 -m pip install "PyYAML>=6.0,<7" "openpyxl>=3.1,<4" "python-docx>=1.2,<2"

Expected result The output ends with Successfully installed … or Requirement already satisfied.

If it doesn't work
  • "No module named pip": your Python installation is incomplete. Reinstall Python from python.org.
  • "externally-managed-environment": this Python came from Homebrew. Install Python from python.org and use that one.
  • Any other error is a local installation problem: contact the facilitator.

If it doesn't work

05

Connect Claude to SAP

WHAT YOU ARE DOING

Letting Claude use the SAP tools that ABAP FS provides. Only start this after Checkpoint 1 passes.

WHY

MCP is the bridge that lets Claude use the SAP tools exposed by ABAP FS. No SAP credentials pass through it; ABAP FS uses your existing connection.

  1. Start the ABAP FS MCP server

    Command Palette → ABAP FS: Start MCP Server.

    Expected result A notification confirms the server is running on port 4847.

    • The server runs inside VS Code. VS Code must stay open.
    • It needs an active IX1 connection. After restarting VS Code, run ABAP FS: Connect to an ABAP system again.
    • Running the command also makes the server start automatically with VS Code from now on.

  2. Add the server to Claude Code

    In the Claude Code panel, type /mcp and press Enter. In the dialog, add a new server with:

    Name
    abap-fs
    Type
    HTTP
    URL
    http://localhost:4847/mcp
    Scope
    User, so it is also available in the project you create later

    Do not add headers, passwords or SAP credentials. If the dialog has no option to add a server, update the Claude Code extension.

    Optional: add it from a terminal instead

    Only if you have separately installed the standalone Claude Code terminal tool. It saves to the same configuration.

    claude mcp add --transport http --scope user abap-fs http://localhost:4847/mcp

  3. Confirm the connection

    Start a new Claude conversation, type /mcp again.

    Expected result abap-fs shows Connected.

  4. Ask Claude to read SAP

    Send exactly this prompt. It is a read-only test.

    Using the ABAP FS tools, search SAP IX1 for the class CL_ABAP_TYPEDESCR and tell me what you find. This is a read-only connection test: do not create, modify, activate or transport anything.

    Claude asks permission to use an ABAP FS search tool. Read the request and allow it. Deny any request to create, change or activate an object.

    Expected result Claude reports that it found CL_ABAP_TYPEDESCR in IX1.

CHECKPOINT 2

Claude can reach SAP

Checkpoint 2 items

If this fails, find the layer:

ABAP FS cannot access IX1
SAP connection problem. Go back to Checkpoint 1.
ABAP FS works, but Claude cannot see its tools
MCP problem. Check that the server is started and /mcp shows abap-fs Connected.
Claude reads SAP, but the Framework cannot proceed
Framework or project problem. That belongs to the exercise, not to setup.
Troubleshoot MCP
  • abap-fs shows Failed: run ABAP FS: Start MCP Server, then use Reconnect in /mcp or start a new conversation.
  • Port 4847 already in use: another program uses it. Contact the facilitator.
  • 401 Unauthorized: an MCP API key is set in ABAP FS settings. Contact the facilitator.
  • Tools time out: the IX1 connection was lost. Reconnect ABAP FS.
  • Server errors are listed in VS Code's Output panel under ABAP FS.

10

Work with Claude

Claude does not replace your engineering judgment.

Claudeproposes · investigates · executes

Youreview · decide · approve

You will meet four kinds of moments:

A · CLAUDE ASKS FOR INFORMATION

“Who is the Technical Lead?”

Answer what you know. If you do not know, say so.

B · CLAUDE FINDS A FUNCTIONAL GAP

“The specification does not define … Please decide.”

For this demo you are also the Functional Owner. Make a reasonable business decision and give it to Claude.

Do not ask the facilitator for the answer.

C · A TECHNICAL DECISION

“I recommend implementing … because …”

Use your SAP expertise. Review the recommendation, ask why, challenge it. Do not accept it blindly.

If Claude asks you to decide a technical question as if it were a business requirement, you can reply:

This is a technical design decision. Please evaluate it through the framework and recommend the appropriate solution.

D · CLAUDE ASKS FOR APPROVAL

“If this is correct, reply: …”

Read exactly what is being approved. Approve only if you agree. Use the wording the Framework shows you.

PERMISSIONS AND SAP SAFETY

  • Claude asks before it changes files or runs commands. Read each request. Allow it when it makes sense; deny it when it does not.
  • Manual mode is required. Do not switch to modes that approve actions for you or skip permission checks.
  • ABAP FS can write to SAP, and changes take effect immediately. The connection test before the exercise was read-only. During the exercise, SAP objects are created or changed only after the Framework has authorized implementation and you have approved the action.
  • Do not ask Claude to change SAP outside the Framework.

Three rules

01

Follow the Framework.

Do not navigate lifecycle files or edit them by hand.

02

Ask before guessing.

Not sure what comes next? Ask Claude:

What should I do next?
03

Don't clean up the result.

Do not delete, rename or reorganize generated artifacts. We review the project exactly as it finished.
